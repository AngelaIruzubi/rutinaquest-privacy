Política de Privacidad — RutinaQuest

Última actualización: agosto de 2026

RutinaQuest es una aplicación móvil diseñada para ayudar a personas con discapacidad intelectual a organizar sus rutinas diarias mediante tareas, pictogramas y gamificación.

1. Datos que NO recogemos

RutinaQuest no recoge ni almacena ningún dato personal identificable del usuario, incluyendo:

  • Nombre, apellidos o alias
  • Dirección de correo electrónico
  • Número de teléfono
  • Ubicación geográfica
  • Datos de pago

2. Datos almacenados localmente

Toda la información que introduces en la app (tareas, rutinas, preferencias del avatar, puntuaciones) se almacena únicamente en el dispositivo local. Estos datos no se transmiten a ningún servidor externo ni son accesibles por terceros.

Si desinstala la aplicación, todos los datos locales se eliminan permanentemente.

3. Herramientas de diagnóstico (Sentry)

Utilizamos Sentry como herramienta de diagnóstico de errores técnicos. Cuando la aplicación experimenta un fallo, Sentry puede recopilar información técnica anónima como:

  • Tipo y versión del sistema operativo
  • Modelo del dispositivo
  • Traza del error técnico
  • Versión de la aplicación

Esta información es estrictamente técnica, no contiene datos personales identificables y se utiliza exclusivamente para mejorar la estabilidad de la aplicación. Consulta la política de privacidad de Sentry.

4. Pictogramas ARASAAC

La aplicación utiliza pictogramas del sistema ARASAAC, cargados desde su API pública (arasaac.org). No implican ninguna recopilación de datos personales.

5. Notificaciones

La aplicación puede enviar notificaciones locales programadas para recordar tareas. Se generan y almacenan localmente en el dispositivo. Puedes desactivarlas desde los ajustes de tu dispositivo.

6. Menores de edad

RutinaQuest está diseñada para ser utilizada por personas de todas las edades, incluyendo menores. Dado que no recogemos ningún dato personal, la aplicación cumple con las normativas de protección de datos para menores.

7. Derechos del usuario

Dado que no recogemos ni almacenamos datos personales en servidores externos, todos tus datos están en tu dispositivo. Puedes eliminarlos en cualquier momento desinstalando la aplicación o borrando los datos desde los ajustes del dispositivo.
